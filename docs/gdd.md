## 1. コンセプト

**「壁に弾を反射させて敵戦車を撃ち抜く、一撃必殺のトップダウン戦車パズルアクション」**

- Wii Play「タンク！」の**メカニクス（ルール）のみ**を仕様として再現する。画像・音源・コード・固有名称は一切流用せず、すべてオリジナル資産で構成する（詳細は §10 知財ポリシー）。
- プラットフォーム：PCブラウザ（デスクトップ優先）。
- プレイ形式：シングルプレイのミッション攻略が軸。ローカル2P協力は**MVP後の拡張**（§12）。
- MVP規模：**5ミッション・敵AI 2種**。

## 2. コアループ（遊びの基本サイクル）

1. ミッション開始：盤面に自機と敵戦車が配置される。
2. 移動と照準を独立に操り、直接射撃または**跳弾**（壁で反射する弾）で敵を撃破する。
3. 敵を全滅させるとミッションクリア → 次のミッションへ。
4. 被弾すると即ミス（一撃死）。残機を1つ失い同ミッションをやり直す。残機が尽きたらゲームオーバー。

**面白さの核**：①一撃死の緊張感、②「反射させれば物陰の敵に当たる」という発見、③自分の弾も自分に当たる（跳ね返りの自爆リスク）ことによる撃ちすぎ抑制。

## 3. 操作仕様

| 入力 | 動作 |
|---|---|
| W / A / S / D | 戦車の移動（8方向。車体は移動方向へ滑らかに向きを変える） |
| マウス移動 | 砲塔（砲台の回転部分）の照準。カーソル位置へ常時追従 |
| 左クリック | 射撃（押しっぱなしで連射はしない。1クリック1発） |
| スペース または 右クリック | 地雷の設置 |
| Esc / P | ポーズ（一時停止） |

- 移動と照準は完全に独立（移動しながら別方向を撃てる）。これが本作の操作の核。
- 8方向移動の斜め入力は速度を正規化する（斜め移動が速くならないようにする）。

| 弾速 | 200 px/s | 通常弾 |
| 同時発射数上限 | 5発 | 自分の弾が場に5発あると撃てない |
| 弾の反射回数上限 | 1回 | 2回目の壁接触で消滅 |
| 発射間隔 | 0.3 s | 連打の最短間隔 |
| 地雷の同時設置上限 | 2個 | |
| 地雷の起爆条件 | 設置後10秒で自動起爆／敵味方の接近（半径40px、戦車中心との距離で判定）で起爆／弾・爆風が触れて誘爆 | ★v0.3：設置者本人は設置後いったん半径外へ出るまで接近起爆の対象外（戻れば起爆＝自爆あり。10秒自動起爆・誘爆に除外はない） |
| 爆風半径 | 48 px | 爆風は敵味方・弾・地雷すべてを巻き込み、破壊可能壁 `X` を消滅させる。★v0.3：爆風は壁で遮蔽されない（円範囲に一律作用） |

## 5. 弾の物理仕様

- 弾は直進し、**壁に当たると入射角＝反射角で反射**する（跳弾）。反射回数が上限を超えたら消滅。
- **弾同士は相殺する**：弾と弾が接触すると両方消滅する（敵弾を撃ち落とせる。原作の重要メカニクスのひとつ）。
- 弾は発射者を問わず全戦車に当たる（自分の跳ね返り弾で自爆あり）。
- 破壊可能壁（§7）に当たった弾は反射せず、壁を破壊はしない（MVPでは壁破壊は地雷の爆風のみ）。

## 5.5 戦車の衝突仕様（v0.2 追加・オーナー承認済み）

- 戦車同士は通り抜けできない（互いに通行不可の障害物として扱う。重なり防止）。
- 戦車は壁タイル（`#`・`X`）と穴（`H`）に進入できない。

## 6. 敵AI仕様（MVP：2種）

> 敵の名称はオリジナル。ステートマシン（状態機械＝「待機・照準・射撃」などの状態遷移で行動を管理する設計）で実装する。

### 敵A「セントリー」（固定砲台型）
| 項目 | 値 |
|---|---|
| 移動 | しない（その場で砲塔だけ回す） |
| 照準 | プレイヤーへ追従（回転速度 115°/s。v0.4で 90→115 に強化）。ときどきランダムにブレる（±2°） |
| 弾速 / 反射上限 | 225 px/s / 1回（v0.4：敵弾のみ 200→225 に強化。プレイヤー弾は200のまま） |
| 同時発射数上限 | 1発 |
| 発射間隔 | 平均 2.2 s（±0.8 s のゆらぎ）（v0.4で 3.0→2.2 に短縮） |
| 射撃条件 | 射線が通り、かつ砲塔がプレイヤー方向 ±0.15 rad（約±8.6°）以内を向いたときのみ（v0.2 で明確化） |
| 跳弾狙撃（v0.4で解禁） | 直接射線が塞がれているとき、外周壁で反射1回して当たる射線があれば低確率（リロードごとに20%）でその反射点を狙って撃つ。物陰も安全地帯にしない |
| 耐久 | 1 |

> 補足（v0.2）：レベルデザイン上、射線が常に遮られる「跳弾専用の的」となるセントリーは一度も反撃しないことがある。これは跳弾を安全に学ばせる配置として意図的に許容する。

### 敵B「ローバー」（遊撃型）
| 項目 | 値 |
|---|---|
| 移動 | 78 px/s でうろつく（数秒ごとにランダムな目標点を選んで移動。壁は回避）（v0.4で 60→78 に強化） |
| 照準 | プレイヤーへ追従（回転速度 150°/s）（v0.4で 120→150 に強化） |
| 弾速 / 反射上限 | 225 px/s / 1回（v0.4：敵弾のみ強化） |
| 同時発射数上限 | 1発 |
| 発射間隔 | 平均 1.5 s（±0.6 s のゆらぎ）（v0.4で 2.0→1.5 に短縮） |
| 特記 | プレイヤーの弾が接近（110px）すると回避移動を試みる（成功率50%。v0.4で 35%→50% に強化） |
| 耐久 | 1 |

### 敵C「スナイパー」（狙撃型・v0.6 追加）
| 項目 | 値 |
|---|---|
| 移動 | しない |
| 照準 | プレイヤーへゆっくり追従（回転速度 70°/s）だが**ブレなし**（精密照準） |
| 弾速 / 反射上限 | **340 px/s** / 1回（見てから避けるのは困難。遮蔽と先読みで対処させる） |
| 同時発射数上限 | 1発 |
| 発射間隔 | 平均 4.0 s（±1.0 s） |
| 射撃条件 | セントリーと同様（射線＋許容角）。**跳弾狙撃の確率は35%**（セントリーの20%より高い） |
| 耐久 / 識別 | 1 / 紫系のオリジナル配色 |

### 敵D「マインレイヤー」（地雷敷設型・v0.6 追加）
| 項目 | 値 |
|---|---|
| 移動 | 70 px/s で徘徊（ローバーと同方式） |
| 地雷敷設 | 同時3個まで。敷設間隔 平均5.0 s（±2.0 s）。最寄りの生存プレイヤーから 160px 以上離れているときのみ敷設（目の前に置く自爆行為を防ぐ） |
| 敵の地雷 | 挙動はプレイヤー地雷と同一（10秒自動起爆・接近起爆40px・誘爆・X壁破壊・爆風は全員に作用）。設置者除外ルール（§4★）も同様に適用。**敷設した敵自身の同時上限にのみ数える** |
| 射撃 | 弾速225 px/s・反射1回・同時1発・発射間隔 平均2.5 s（±1.0 s）。条件はローバーと同様 |
| 照準 | 120°/s |
| 耐久 / 識別 | 1 / 黄系のオリジナル配色 |

## 7. ステージ仕様

- 盤面：**タイルグリッド（マス目）方式**。1タイル = 32 px、盤面 = 25×17 タイル（800×544 px）＋外周は必ず壁。
- タイル種別（MVP）：
  - `.` 床 … 通行・弾通過可
  - `#` 恒久壁 … 通行不可・弾は反射
  - `X` 破壊可能壁 … 通行不可・弾は消滅（反射しない）・地雷の爆風で消滅・敵AIの射線判定でも遮蔽扱い（v0.2.1 明確化）
  - `H` 穴 … 戦車は通行不可・**弾は上を通過する**（撃ち合い専用の地形）
- ステージデータはコードから分離：Phase 1 は文字列グリッド、Phase 2 以降は JSON ファイル。

### MVP ミッション構成（各面の設計意図）

| ミッション | 敵構成 | 教えたいこと |
|---|---|---|
| M1 | セントリー×1 | 移動・照準・射撃の基本。遮蔽物なしの広場 |
| M2 | セントリー×2 | 跳弾の発見。正面が壁で塞がれ、反射でしか当てられない配置 |
| M3 | ローバー×1 | 動く敵への偏差（相手の未来位置を狙う）と弾の撃ち落とし |
| M4 | セントリー×1＋ローバー×1 | 複数対処の優先順位。地雷で破壊可能壁を開通するルート短縮も可能 |
| M5 | セントリー×2＋ローバー×2 | MVP総まとめ。穴（H）越しの撃ち合いを含む |

## 8. 進行・UI仕様

- 残機：初期3。ミッションクリアは持ち越し、被弾で1減。0でゲームオーバー（M1からやり直し・残機3に戻す。MVPではセーブなし）。
- ミッション間に「MISSION n」表示（2秒）→ 開始。開始後1秒間は敵は射撃しない（開幕即死防止）。★v0.3：被弾によるミッションリセット時も同じバナー2秒から再開する。
- ★v0.3：M5クリアで全クリア画面を表示し、R またはクリックでタイトルへ戻る。
- HUD（画面上の常時表示情報）：ミッション番号、残機、撃破数。
- ポーズ中は全更新を停止し、半透明オーバーレイ（覆い）で「PAUSED」表示。

## 9. アート・サウンド方針（asset-advisor 管轄）

- ビジュアル：**フラットなブロック調のオリジナルデザイン**。図形の組み合わせ（矩形＋円）でコード描画から始め、原作と配色・シルエットを明確に差別化する。
- 効果音：Web Audio API（ブラウザ内蔵の音声合成機能）で自作合成 → 不足分は CC0（著作権放棄）素材。外部素材は `assets/CREDITS.md` に出所・ライセンスを必ず記録。
- BGM：MVPでは無しでも可（効果音優先）。

## 10. 知財ポリシー（全員厳守）

1. 任天堂の画像・音源・3Dモデル・コード・ロゴ・固有名称は一切使用・参照取り込みしない。
2. 再現するのは著作権保護の対象外である「ルール（メカニクス）」のみ。表現（見た目・音・文言）はすべてオリジナル。
3. 見た目の類似もリスクとして扱い、配色・シルエットを意図的に変える。
4. 正式名称の決定時は既存商標との衝突を簡易確認する。

## 11. 技術方針

- **Phase 1**：素の HTML5 Canvas + JavaScript の1ファイル（`prototype/index.html`、依存ゼロ）で核メカニクス（移動・照準・跳弾・相殺・敵A）を検証。
- **Phase 2 以降**：Phaser（2Dゲーム用フレームワーク）+ Vite（高速ビルドツール）+ TypeScript（型付きJS、strict）。ロジックはシーンから分離し Vitest（テストツール）で単体テスト。
- フレームレート非依存（デルタタイム更新）を Phase 1 から徹底する。

## 12.5 ローカル2P協力 仕様（v0.5・Phase 4 第1弾）

- **モード選択**：タイトル画面で「1人で出撃／2人で出撃」を選ぶ。2人プレイはミッション構成・敵配置とも1人用と同一（MVPでは敵の増員なし）。
- **操作**：
  - 1P＝従来どおり WASD 移動＋マウス照準＋左クリック射撃＋スペース地雷。
  - 2P＝**両対応**。ゲームパッド（Gamepad API＝ブラウザのコントローラ対応機能）接続時は左スティック移動・右スティック照準（傾けた方向へ砲塔即応）・R1/RB 射撃・L1/LB 地雷。未接続時はキーボード分割：矢印キー移動・IJKL で砲塔を8方向へ向ける（押した組み合わせの方向へ砲塔が回転追従）・Enter 射撃・右Shift 地雷。
  - パッドの接続・切断は2Pの生存中でも随時切替可（毎フレーム接続状態を確認）。
- **共有ルール**：残機は2人で共有（初期3のまま）。弾・地雷の上限（5発・2個）は**プレイヤーごと**に独立。
- **ダウンと復帰**：被弾したプレイヤーはそのミッション中は退場（機体消滅）。**両者とも退場した時点で**残機-1・ミッションリセット。片方が生存したままクリアすれば退場側もペナルティなしで次ミッションから復帰。
- **フレンドリーファイア**：§5 のとおり弾・地雷・爆風は発射者・設置者を問わず全戦車に作用する（相方も撃てば倒せてしまう。協力の緊張感として意図的に維持）。
- **敵AIの標的**：セントリー・ローバーとも「生存中のプレイヤーのうち、射線が通る最も近い1体」を狙う。全員に射線が通らなければ最も近い1体を照準だけ追従（跳弾狙撃の判定も同じ標的に対して行う）。
- **識別**：1P＝青系（従来色）、2P＝緑系のオリジナル配色。HUD に P1/P2 の状態（生存/退場）を表示。
- **カメラ**：盤面全体が1画面に収まっているため分割・スクロールなし（現状維持）。
- **実装細部（v0.5.1 暫定解釈・★オーナー確認待ち）**：
  - 2Pの初期位置はステージデータに持たず「P1の隣接床タイル」を自動探索（右→左→下→上→斜め→距離2の順。全ミッションで確保できることをテストで担保）。
  - IJKL照準の砲塔回転速度は540°/s（調整値）。パッドのスティックデッドゾーン（誤入力防止の不感帯）は0.25、射撃・地雷は押下エッジ検出（1押下1発）。
  - パッドの移動は傾き量によらず常時フルスピード（§4の移動速度単一値に合わせる）。
